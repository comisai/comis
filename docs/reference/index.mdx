The Reference tab contains the complete technical specifications for Comis. Use these pages when you need exact syntax, all available options, or precise behavioral contracts.

## Groups

**CLI** — Every command group and its flags, verified against `comis --help`.

**Configuration** — The full `config.yaml` schema, environment variables, hot-reload behavior, secret manager config, and the delivery queue reference.

**Security** — The security model, sandbox policy, safe-path rules, action classifier, tool security, and Node.js permission model.

**Gateway** — HTTP gateway, JSON-RPC, WebSocket, experimental OpenAI-shaped
endpoints, webhooks, rate limiting, and ACP server.
