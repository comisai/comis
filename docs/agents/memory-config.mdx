**What this page is.** The complete reference for Comis's agent-memory capabilities and the
exact config option for each. **As of v1 the memory features are ON by default (opt-out)** —
a fresh install runs them and you edit config to turn them off. Two capabilities deliberately
stay OFF: **`socialModeling`** (gated on a privacy-review sign-off — it models third parties)
and the v2.26 outcome-gated learning loops **`learningTuning`** / **`learningForgetting`**
(default-off, see [Outcome-gated ranking & forgetting](#outcome-gated-ranking--forgetting-v2-26)). The trust boundary
(`rag.scoring.trustAlpha`, `rag.includeTrustLevels`) is **frozen** — not a tunable capability.

<Warning>
  The LLM **build/ask** features (review, consolidation, reasoning, user-representation,
  usefulness-judge, online-tuning, and `memory_ask`) spend **your own** LLM/API budget. They
  are on by default in v1, and the daemon prints a first-run notice listing what's active.
  **One line turns all of them off:** `memory.costFeatures.enabled: false`.
</Warning>

**Where the config lives.** Capabilities are configured **per agent** under
`agents.<agentId>.` in `~/.comis/config.yaml`. The shared **memory engine** (store +
embeddings + reranker + the cost kill switch) is the top-level `memory:` block. The config
below is the **effective default** — set any `enabled: false` to opt a feature out.

<Note>
  On by default is necessary but not always sufficient — several capabilities also need
  *built derived state* (a populated graph, learned weights, scored usefulness) before they
  change recall. See [Dependencies & gotchas](#dependencies--gotchas) below.
</Note>

## Default config (v1 — opt-out)

This is the **effective default** a fresh install runs. To opt out, set the relevant
`enabled: false` (or flip the master `memory.costFeatures.enabled: false` to silence all
LLM-cost features at once).

```yaml
# ─────────────────────────────────────────────────────────────────────────
# 1. MEMORY ENGINE (top-level) — the substrate every capability runs on
# ─────────────────────────────────────────────────────────────────────────
memory:
  dbPath: memory.db
  walMode: true
  embeddingModel: text-embedding-3-small   # hosted (1536d). Point at a local GGUF for on-device.
  embeddingDimensions: 1536
  rerankerModel: "hf:gpustack/bge-reranker-v2-m3-GGUF:bge-reranker-v2-m3-Q8_0.gguf"  # local by default
  rerankerModelsDir: models
  rerankerGpu: auto                 # auto | metal | cuda | vulkan | false
  rerankerThreads: 4
  compaction: { enabled: true, threshold: 1000, targetSize: 500 }
  retention: { maxAgeDays: 0 }      # 0 = keep forever
  costFeatures:
    enabled: true                   # MASTER KILL SWITCH — set false to disable ALL LLM cost features at once

agents:
  my-agent:
    # ───────────────────────────────────────────────────────────────────
    # 2. RECALL + RECALL-TIME CAPABILITIES  (agents.<id>.rag)
    # ───────────────────────────────────────────────────────────────────
    rag:
      enabled: true                 # recall is ON by default
      maxResults: 5
      minScore: 0.1
      includeTrustLevels: [system, learned]   # trust filter — FROZEN (see Trust note)
      rerank:
        enabled: true               # default false; cross-encoder rerank (local bge)
        maxCandidates: 40
        minResults: 1
        timeoutMs: 800
      scoring:                      # ranking weights, each 0..1
        recencyAlpha: 0.2
        temporalAlpha: 0.2
        proofAlpha: 0.1
        trustAlpha: 0.1             # FROZEN — leave at the shipped value
        usefulnessAlpha: 0.1        # magnitude of the recall-utility (FEED) loop
        forgetAlpha: 0.1            # magnitude of FadeMem (FORGET) decay
      lanes:
        fts: { weight: 1.0 }
        vector: { weight: 1.5 }
        temporal: { enabled: true, weight: 1.0, windowDays: 7 }            # default off
        causal:   { enabled: true, weight: 1.0 }                           # default off
        graphSpread: { enabled: true, weight: 1.0, maxDepth: 2, fanOut: 8 } # KG lane — default off
      entityLane: { enabled: true, seedCount: 5, perEntityCap: 200, weight: 1.0 }  # default off
      mmr: { enabled: true, lambda: 0.7 }       # MMR diversity re-rank — default off
      feedback: { enabled: true }               # FEED recall-utility loop (uses scoring.usefulnessAlpha)
      forget: { enabled: true }                 # FORGET decay gate (uses scoring.forgetAlpha)
      queryUnderstanding:                       # LEARN-IQ (LLM-free)
        intentReweight: true
        synonyms: true
        temporalParse: true

    # ───────────────────────────────────────────────────────────────────
    # 3. BUILD-PATH / TOOL CAPABILITIES (write memory; some run on a cron)
    # ───────────────────────────────────────────────────────────────────
    socialModeling:                  # SOCIAL — directional relationship model
      enabled: true
      privacyReviewSignedOffBy: "your-name-here"   # REQUIRED — stays OFF without a non-empty sign-off
      schedule: "0 6 * * *"
      maxEntriesPerRun: 50
      maxSourceMemories: 200

    dialectic:                       # memory_ask grounded-Q&A tool (the one query-time LLM surface)
      enabled: true
      maxOutputTokens: 1024
      maxRecall: 10

    # ───────────────────────────────────────────────────────────────────
    # 4. MAINTENANCE / LIFECYCLE JOBS (cron-driven; default off)
    # ───────────────────────────────────────────────────────────────────
    memoryReview:                    # session → memory review + dedup
      enabled: true
      schedule: "0 2 * * *"
      minMessages: 5
      maxSessionsPerRun: 10
      maxReviewTokens: 4096

    memoryUsefulnessJudge:           # scores recall-utility → feeds the FEED loop
      enabled: true
      schedule: "0 7 * * *"
      maxSourceMemories: 200
      maxSourceChars: 24000

    memoryLifecycle:                 # FORGET sweep / tier promote-demote (soft eviction gated by learningForgetting, below)
      enabled: true
      schedule: "0 9 * * *"
      thetaPromote: 0.7
      thetaDemote: 0.3

    # ───────────────────────────────────────────────────────────────────
    # 5. VERIFIED LEARNING — outcome-gated ranking & forgetting (v2.26; default OFF)
    # ───────────────────────────────────────────────────────────────────
    learningTuning:                  # LEARN-TUNE — gates the outcome-reward write (recordUsage/recordFailure → failure_count)
      enabled: true                  # default ON (opt-out); force-disabled by memory.costFeatures.enabled: false

    learningForgetting:              # LEARN-FORGET — wrongness-based soft eviction
      enabled: true                  # default ON (opt-out); force-disabled by memory.costFeatures.enabled: false
      eviction:
        enabled: true                # the parent `enabled` is the real gate
        strengthThreshold: 0.2       # strength floor below which a non-pinned/non-system memory is soft-evicted
        failureEvictionFloor: 3      # corroborated failure_count at/above which a non-exempt memory is soft-evicted regardless of strength (RAISE for a more conservative policy)
      failurePenalty: 0.5            # weight on a memory's failure_count when decaying strength [0..1]
```

## Capability → config map

| Capability | Enable knob (`agents.<id>.`) | What it does |
|---|---|---|
| Recall (base) | `rag.enabled` *(default true)* | Hybrid FTS + vector recall, fused + scored |
| Rerank | `rag.rerank.enabled` | Local cross-encoder rerank of the top candidates |
| Temporal lane | `rag.lanes.temporal.enabled` | Recency-window recall lane |
| Causal lane | `rag.lanes.causal.enabled` | Cause/effect-linked recall lane |
| **KG** graph-spread | `rag.lanes.graphSpread.enabled` | Walks the knowledge graph from top hits (LLM-free) |
| Entity lane | `rag.entityLane.enabled` | Entity-seeded recall expansion |
| MMR diversity | `rag.mmr.enabled` | Maximal-marginal-relevance diversification |
| **FEED** loop | `rag.feedback.enabled` | Boosts memories that proved useful (`scoring.usefulnessAlpha`) |
| **LEARN-IQ** | `rag.queryUnderstanding.intentReweight` (+ `synonyms`, `temporalParse`) | LLM-free query understanding / lane reweighting |
| **FORGET** | `rag.forget.enabled` | FadeMem per-type decay demotes stale memories (`scoring.forgetAlpha`) |
| **REFLECT** (incl. profile + topic) | `learningSkills.enabled` | The one outcome-gated reflection cron — maintains the learned **skill** docs, the per-user **profile** doc (was USER), and higher-order **topic** observations (was REASON/Consolidation) in one pass |
| **SOCIAL** | `socialModeling.enabled` **+** `socialModeling.privacyReviewSignedOffBy` | Directional relationship model (double-gated) |
| **DIALECTIC** | `dialectic.enabled` | The `memory_ask` grounded-Q&A tool (query-time LLM) |
| Review | `memoryReview.enabled` | Turns sessions into reviewed memories |
| Usefulness judge | `memoryUsefulnessJudge.enabled` | Scores recall-utility (the FEED signal source) |
| Lifecycle | `memoryLifecycle.enabled` | Tier promote/demote + the FORGET sweep (the soft-eviction behaviour is gated by `learningForgetting`, below) |
| **LEARN-TUNE** (v2.26) | `learningTuning.enabled` *(default true, opt-out)* | Gates the **outcome-reward write** — success→`recordUsage` / failure→`recordFailure` on the `memory_usefulness` store (the `failure_count` source that **LEARN-FORGET** reads). Composes with `memoryUsefulnessJudge` + `learningForgetting` |
| **LEARN-FORGET** (v2.26) | `learningForgetting.enabled` *(default true, opt-out)* | Wrongness-based **soft** eviction: a memory recalled into failed/corrected outcomes decays faster and is soft-evicted (`evicted_at`, reversible, never hard-deleted). Composes with `memoryLifecycle` + `rag.forget` |

<Note>
  **v2.31 fold:** the standalone **USER** (`memoryUserRepresentation`), **REASON** (`memoryReasoning`), and **Consolidation** (`memoryConsolidation`) crons + their config keys were **removed in v2.31** — the work folds into the **one learning-reflection cron** (gated by `learningSkills.enabled`), which maintains the per-user **profile** doc and higher-order **topic** observations in the same pass as the learned **skill** docs (one outcome-gated engine, anti-poison two-axis). A profile **correction** is preserved non-destructively (bi-temporal history-append on the Mental Model doc), not overwritten. Those three keys no longer parse; remove them from any config.
</Note>

## Outcome-gated ranking & forgetting (v2.26)

**Verified Learning** gates **forgetting** on a **real task outcome** (the v2.26 `outcome_events` signal) instead of a text-overlap proxy, and feeds that outcome into a per-memory recall-utility ledger. Both knobs **default ON (opt-out)**, gated by the master `memory.costFeatures.enabled` switch (also default on) — so a default install **does** record outcome reward and forget by wrongness. Set a per-agent flag (`learningTuning.enabled` / `learningForgetting.enabled`) **or** the master `memory.costFeatures.enabled` to `false` to opt out. Recall ranking itself is the **fixed `rag.scoring`** fusion (deterministic RRF + the cross-encoder reranker) — the v2.26 per-intent tuned-alpha bandit was **removed in v2.31** (it never validated a recall lift).

- **Outcome reward (the ranking-signal write)** — `agents.<id>.learningTuning.enabled` gates the **outcome-reward write**: when a recalled memory rides a `success` trajectory the daemon calls `recordUsage` on the `memory_usefulness` store, and on `failure`/`corrected` it calls `recordFailure` (incrementing the memory's outcome-attributed `failure_count`). This write is the **`failure_count` source** that LEARN-FORGET reads; it no longer tunes any recall weight (recall stays the fixed `rag.scoring`). It composes with `memoryUsefulnessJudge` (the recall-utility signal) + `learningForgetting` (the forgetting consumer).
- **Forgetting** — `agents.<id>.learningForgetting.enabled` couples a memory's decay to its outcome-attributed `failure_count`, so **wrong fades faster than merely old**, and **soft-evicts** a sufficiently weak memory: it is marked `evicted_at` (excluded from recall, still resolvable via `asOf`/inspect, **reversible**, never hard-deleted). A memory implicated in **`eviction.failureEvictionFloor`** (default 3) or more **corroborated** failures is soft-evicted regardless of its decayed strength — the recall-shape strength floors above the threshold, so this floor is what makes wrongness-eviction reachable. A **corroboration gate** (≥2 independent failures, or one deterministic source, on every `failure_count` increment) and **exemptions** for pinned / `system` / high-`proof_count` memories make induced eviction impractical: a poisoner cannot evict a well-corroborated, pinned, or system memory no matter how many failures it induces. It composes with `memoryLifecycle` (the sweep schedule) + `rag.forget` (score-decay).

See [`learningTuning` / `learningForgetting` in config-yaml](/reference/config-yaml#learning-tuning-agents-learningtuning) for every key and default, and the [`memory_usefulness` / `evicted_at`](/operations/data-directory#ranking--forgetting-verified-learning-v2-26) storage. The forgetting loop emits **counts-only** signals (`learning:memory_demoted` / `learning:memory_evicted`) for `comis explain` / `comis fleet`.

## Deepened user model: revise (folded into reflection, v2.31)

The per-user **profile** and higher-order **topic** observations are now maintained by the one outcome-gated reflection cron (`learningSkills.enabled`) as `kind:"profile"` / `kind:"topic"` Mental Model docs — the standalone user-representation + consolidation/reasoning crons were removed in v2.31 (see the fold note above). The non-destructive revision semantics carry over: a profile **correction** **supersedes** the prior doc with a bi-temporal **history-append** (the prior body is preserved in the doc's `history`, never hard-deleted), and external-trust sources are excluded by the engine's two-axis anti-poison SELECT. The activity surfaces **counts-only** through `comis explain` / `comis fleet` (the `learning` signal's reflection counts). The full key-by-key rewrite of this section lands in a later v2.31 docs pass.

## Dependencies & gotchas

1. **Some capabilities need built derived state, not just the flag:**
   - **KG** (`rag.lanes.graphSpread`) is a no-op until the knowledge graph is populated with
     entities/edges.
   - **FEED** (`rag.feedback`) is meaningful once `memoryUsefulnessJudge` has scored recalls.
   - **FORGET** demotion (`rag.forget`) shows up at recall; **eviction** is the `memoryLifecycle`
     sweep — live as **soft, reversible** eviction (`evicted_at`) when the v2.26
     `learningForgetting` gate is enabled (default-off), exempting pinned/system/high-proof
     memories. See [Outcome-gated ranking & forgetting](#outcome-gated-ranking--forgetting-v2-26).
2. **SOCIAL is double-gated.** `enabled: true` does nothing on its own; it activates only with
   a non-empty `socialModeling.privacyReviewSignedOffBy` operator sign-off.
3. **`dialectic` (`memory_ask`) spends tokens per ask** — it is the only query-time LLM
   surface in the memory stack. Everything else in recall is LLM-free.
4. **Trust is frozen, not a tunable capability.** `rag.scoring.trustAlpha` and
   `rag.includeTrustLevels` are the trust hard-boundary; leave them at the shipped values.
5. **On by default in v1 — watch your spend.** The LLM build/ask features are opt-out for v1
   so operators get the full memory stack from day one; they spend your own budget. Your
   controls are the first-run notice and the master switch `memory.costFeatures.enabled: false`
   (or per-feature `enabled: false`). Measure the effect in your own domain — Comis's honest,
   reproducible methodology and the latest costed results are on the
   [Memory benchmarks](/agents/memory-benchmarks) page.
