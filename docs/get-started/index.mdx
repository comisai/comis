Comis is an Apache-2.0 governed agent runtime for operators who need
multi-agent systems they can inspect, constrain, recover, and run on
infrastructure they control.

It is built for AI platform engineers, self-hosted operators,
security-conscious builders, and technical teams moving persistent agents onto
real tools and data. Comis is under active development, so start with one agent
and one bounded workflow, verify the deployment on your host, and expand
authority only after the controls are tested.

## Why Comis

**Comis's advantage is coherence.** Formal execution, recoverable context,
provenance-aware memory, scoped authority, bounded spend, and operational
evidence work as one system.

## Start here

```bash
npm install -g comisai
comis init
comis daemon start
```

The setup wizard defaults to encrypted credential storage. Back up the
generated master key separately, then follow the [Quickstart](/get-started/quickstart)
to verify the daemon, your first agent, and the security posture.

Comis runs on infrastructure you control. Configured model, embedding, channel,
media, and tool providers can still receive data routed to them.
