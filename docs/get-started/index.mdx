Comis is an open-source, security-first platform for AI agent teams. It runs on
infrastructure you control and connects agents to a web dashboard and ten
documented messaging adapters: Discord, Telegram, Slack, WhatsApp, Signal,
iMessage, LINE, IRC, Email, and Microsoft Teams.

Comis is under active development. Start with one agent and one interaction
surface, verify the security posture for your host, and expand only after the
basic path is working.

## Start here

```bash
npm install -g comisai
comis init
comis daemon start
```

The setup wizard has several stages and optional integrations. It defaults to
encrypted credential storage; back up the generated master key. Follow the
[Quickstart](/get-started/quickstart) for the complete, verified workflow.
