BROKER-01 test cases — all must be RED before implementation:

session token issuance:
- issueToken("agent-1") returns { sessionId: string, proxyToken: string }
- proxyToken is a non-empty base64url string (no padding, URL-safe chars only)
- two issueToken calls return different sessionIds and different proxyTokens
- issueToken does NOT store the plaintext proxyToken — stores Buffer.from(token, "base64url")

consumeToken — happy path:
- consumeToken(proxyToken) after issueToken returns { sessionId, agentId: "agent-1" }
- sessionId returned by consumeToken equals the sessionId returned by issueToken

consumeToken — security invariants (these must test fail-closed behavior):
- consumeToken with empty string returns null — no throw
- consumeToken with a forged token (different random bytes) returns null
- consumeToken with a SHORTER token (length mismatch) returns null and does NOT throw (length-guard before timingSafeEqual)
- consumeToken with a LONGER token (length mismatch) returns null and does NOT throw

single-use semantics:
- consumeToken with the correct token a second time returns null (token already consumed)
- consumeToken after endSession(sessionId) returns null (token invalidated)

endSession:
- endSession with an unknown sessionId does nothing (no throw)

TTL reaper (lazy eviction at consumeToken time):
- consumeToken with a valid token AFTER the TTL has elapsed returns null
- consumeToken with a valid token JUST BEFORE the TTL has elapsed returns SessionInfo (still valid)
- clock.advance(ttlMs + 1) triggers eviction; clock.advance(ttlMs - 1) does not

All behaviors start RED (session-manager.ts does not yet exist).

```
/**
 * SessionManager — single-use timing-safe proxy token lifecycle.
 * @module
 */
import { timingSafeEqual, randomUUID } from "node:crypto";
import { generateStrongToken } from "@comis/core";
import type { ClockPort } from "@comis/core";
```

Internal type (not exported):
```typescript
interface SessionEntry {
  tokenBuf: Buffer;
  agentId: string;
  active: boolean;
  createdAtMs: number;
}
```

Exported interfaces:
```typescript
export interface SessionManagerDeps {
  clock: ClockPort;
  sessionTtlMs?: number;   // default: 60 * 60 * 1000 (1 hour)
}

export interface IssuedSession {
  sessionId: string;
  proxyToken: string;
}

export interface SessionInfo {
  sessionId: string;
  agentId: string;
}

export interface SessionManager {
  issueToken(agentId: string): IssuedSession;
  consumeToken(rawToken: string): SessionInfo | null;
  endSession(sessionId: string): void;
}
```

Factory implementation notes:
- Use `randomUUID()` from node:crypto for sessionId
- Use `generateStrongToken()` for proxyToken (48 bytes, base64url)
- Store `Buffer.from(proxyToken, "base64url")` in the Map — NOT the string
- tokenEquals internal function: `if (a.length !== b.length) return false; return timingSafeEqual(a, b);`
- consumeToken: convert `rawToken` to Buffer with `Buffer.from(rawToken, "base64url")`, then scan the Map
- TTL check in consumeToken: `if (clock.now() - entry.createdAtMs > sessionTtlMs) { sessions.delete(id); continue; }` — lazy eviction
- No raw throw anywhere in this module

NO `Date.now()` — all timestamps via `deps.clock.now()`.
